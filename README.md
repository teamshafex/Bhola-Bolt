# 🚀 BHOLA 2.0 — Standalone Sci-Fi UI Preview Kit

> **Designed for**: [Bolt.new](https://bolt.new), [v0.dev](https://v0.dev), and rapid UI/UX redesign experiments.  
> **Completely decoupled**: 100% self-contained Vite + React 19 + Tailwind v4 project with rich mock data.  
> **Zero backend dependencies**: Zero Supabase keys, zero Google OAuth tokens, and zero monorepo coupling required.

---

## 🎮 What is inside this Preview Kit?

This standalone folder contains **the entire Streamer Web Dashboard (`apps/web`)** bundled with a lightweight, in-memory mock state layer:

- **HUD Shell & Navigation**: `HeaderBar.tsx`, `Sidebar.tsx`, `MobileNav.tsx`
- **Command Center Panels**:
  - `TelemetryPanel.tsx`: Token burn meter, co-host status card, and daily limits.
  - `VibeControlPanel.tsx`: Roast intensity slider (1-10), frequency toggles, and custom slangs.
  - `LiveFeedPanel.tsx`: Live stream chat monitor with interactive inline simulator.
  - `AudienceMatrixPanel.tsx`: Chatter tracking, loyalty tags, and role pills.
- **Showrooms & Sub-pages**:
  - `PersonaHubPage.tsx`: Co-host showroom (Bandya, Bhola, Babu Rao).
  - `SettingsPage.tsx`: Streamer channel settings and YouTube moderator checklist.
  - `SessionHistoryPage.tsx`: Broadcast logs and token audit trail.
- **Modals & Overlays**: `PricingModal.tsx`, `MockCheckoutModal.tsx`, `AddChatterModal.tsx`, `ToastContainer.tsx`.
- **Onboarding Flow**: 5-step interactive wizard (`Step1Welcome`, `StepSelectChannel`, `Step2Persona`, `Step3ModWizard`, `Step4PlanSelect`).
- **Floating HUD Controller**: In the bottom-right corner, allowing you to instantly toggle Stream Status (`LIVE` / `PREMIERE` / `OFFLINE`) and Subscription Tiers (`Starter` / `Pro` / `Studio`).

## ⚡ How to use with Bolt.new

### Method 1: Push to a fresh GitHub Repo (Easiest & Best for Bolt)
1. Initialize a new git repo inside this `preview-kit` folder:
   ```bash
   cd preview-kit
   git init
   git add .
   git commit -m "Bhola 2.0 Preview Kit"
   ```
2. Push it to a new GitHub repository (e.g. `bhola-preview-kit`).
3. Open `https://bolt.new/github/YOUR_USERNAME/bhola-preview-kit`.
4. Bolt will spin up a live interactive WebContainer dev server in seconds!

### Method 2: Drag & Drop into Bolt.new / StackBlitz
1. Zip the `preview-kit` folder into `preview-kit.zip`.
2. Drag and drop the zip file or folder directly into Bolt.new or StackBlitz.

### Method 3: Run Locally on your computer
```bash
cd preview-kit
npm install
npm run dev
```
Open `http://localhost:3000` to see the live dashboard!

## 🔒 Safety & Monorepo Protection

- This folder is **completely isolated** from the main `bhola-platform` monorepo.
- Any edits made in Bolt.new or inside `preview-kit` **will NOT break** your Supabase backend, Google OAuth tokens, or YouTube live chat worker!
- Once you love the design generated by Bolt, we can easily port back the sleek JSX/Tailwind classes into `apps/web/`.
